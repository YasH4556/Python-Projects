# 🧠 Python Reinforcement Learning Projects

Welcome! 👋

This repository contains my Reinforcement Learning projects built with **Python**, **Gymnasium**, **NumPy**, and **Matplotlib**.

I'm using these projects to learn how an AI agent can interact with an environment, receive rewards, learn from its actions, and improve over time.

---

## 📂 Projects

### 🃏 Blackjack AI

A Reinforcement Learning agent trained to play the **Blackjack-v1** environment from Gymnasium.

**Concepts explored:**

- Q-Learning
- Q-Tables
- Epsilon-Greedy Exploration
- Exploration vs Exploitation
- Learning Rate
- Discount Factor
- Epsilon Decay
- Reward-Based Learning

📄 **File:** `BlackJack_Ai.py`

---

### 🤖 Acrobot AI

A Reinforcement Learning agent trained in the **Acrobot-v1** environment from Gymnasium.

The goal is to learn which actions to take based on the current state of the environment and improve its performance through training.

**Concepts explored:**

- Q-Learning
- State and Action Spaces
- Rewards
- Epsilon-Greedy Strategy
- Learning Rate and Discount Factor
- Training over multiple episodes
- Tracking training performance

📄 **File:** `Acrobot_Ai.py`

Some of the main concepts I'm exploring are:

- How an agent learns from rewards

- Exploration vs exploitation
- Q-Learning and Q-Tables
- Epsilon-Greedy strategies
- Training agents over many episodes
- Measuring and visualizing learning progress

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YashH456/Python-Projects.git
```

Move into the project folder:

```bash
cd Python-Projects
```

Install the required libraries:

```bash
pip install gymnasium numpy matplotlib
```
